# Week 2 사례 증거 장부

## Plan 질문과 대표님 답변

### 기존 업무 흐름

1. 사무실 방문으로 신뢰를 확인한 뒤 매도 의뢰를 받는다.
2. 전화 의뢰는 정보가 부족해 여러 차례 통화하고 방문을 유도한다.
3. 기본 입력은 매물 주소, 매도가, 현재 보증금·월세·임대현황이다.
4. 등기사항전부증명서와 토지이용계획 자료를 확보한다.
5. 고객 설명과 공적장부의 차이를 의뢰인에게 다시 물어 좁힌다.
6. 주변 입지·상권과 모든 임대차계약서를 검토한다.
7. 매수희망인에게 방문을 유도해 사무실 브리핑 후 자료를 전달한다.

### 반복 문제

- 매도가 조정 요청이 많다.
- 실제 임대현황의 보증금·월세 일치성, 임차기간, 계약서 내용이 누락되기 쉽다.
- 기존 소요 시간은 사전 추정하지 않고 실제 파일럿에서 측정한다.

### 확정 선택

- 실제 상가·빌딩 1건을 첫 파일럿으로 사용한다.
- 고객용 제안서와 공인중개사 내부 검수표를 분리한다.
- 3단계 사람 승인과 동일 사례 Before/After 실측을 적용한다.
- Hermes 연동과 브라우저 화면 자동조작은 후속 확장으로 둔다.
- 원본과 마스킹 Drive 폴더를 분리하고 마스킹 자료만 처리한다.

## Plan 모드와 Goal의 사례 가치

대표님은 구현 전에 Plan 질문을 충분히 주고받아 실제 반복업무, 입력자료, 누락 지점, 결과 사용 상황과 성공 기준을 도출하기로 결정했다. 이 준비 과정 자체를 사례글 산출물로 남기며, 공개 실용보드의 `계획 → 실행 → 검증 → DB 저장 → 다음 실험` 원리와 연결한다.
