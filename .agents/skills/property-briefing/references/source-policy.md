# 근거 우선순위와 상태 규칙

## 정보 성격별 우선순위

### 권리·면적·용도·임대차

1. 발급 원문 공부서류와 체결된 계약서
2. 기준일이 표시된 공공 MCP/API 조회
3. 의뢰인 설명
4. 현장·광고 메모

원문과 최신 조회가 다르면 최신값으로 덮어쓰지 않는다. 두 값, 각 기준일, 차이와 대표님 판단을 함께 남긴다.

### 입지·상권·교통·개발계획·시세

1. 실행일 현재의 지자체·국토교통부·교통기관 등 공식 자료
2. 공공 실거래 및 통계
3. 확인일이 표시된 현장 자료
4. 의뢰인·광고 메모

계획 발표, 보도자료와 확정 고시를 구분한다. 개발호재는 확정 여부와 사업 단계를 표시한다.

자산가치 관련 근거는 증거 상태와 별도로 다음 사업 단계 중 하나를 붙인다.

| 사업 단계 | 적용 기준 |
|---|---|
| 현재 확인 | 현재 이용 가능한 역·도로·상권 등 현황이 공식 자료로 확인됨 |
| 계획 반영 | 도시기본계획·지구단위계획·철도망계획 등에 반영됐으나 시설이 완료되지 않음 |
| 추진 중 | 인허가·사업자 선정·착공 등 실행 절차가 공식 자료로 확인됨 |
| 추가 확인 필요 | 보도·민간 매체에는 있으나 현재 공식 사업 단계가 확인되지 않거나 지연·변경 가능성이 큼 |

`계획 반영`과 `추진 중`을 `개통 확정`, `사업 완료`, `가치상승 확정`으로 바꾸지 않는다.

## 상태 정의

| 상태 | 적용 기준 |
|---|---|
| 확인됨 | 지정 원문과 교차근거가 일치함 |
| 불일치 | 출처별 값이 서로 다름 |
| 자료 없음 | 해당 정보를 담은 자료가 제공되지 않음 |
| 추가 확인 필요 | 자료는 있으나 원문 대조·현장·당사자 확인이 더 필요함 |
| 기준일 경과 | 자료는 있으나 현재 설명에 쓰기에는 기준일이 오래됨 |
| 판독 불가 | 이미지·스캔 품질, 페이지 손상 등으로 값을 신뢰성 있게 읽을 수 없음 |

`확인됨`은 해당 항목이 지정 원문에서 판독되고 비교 가능한 독립 근거와 일치할 때 사용한다. 단일 메모만 있거나 비교 근거를 조회하지 않은 값은 `추가 확인 필요`로 둔다.

`기준일 경과`에 일률적인 일수 기준을 임의로 만들지 않는다. 다음 중 하나가 확인될 때 사용한다.

- 문서에 적힌 유효기간 또는 사용자가 정한 업무 기준일이 지남
- 더 최신의 공식 발급·조회 자료가 존재함
- 현재 상태 설명이 필요한 항목인데 실행일 기준 재조회가 되지 않았고 기존 자료만으로 현재성을 뒷받침할 수 없음

단순히 오래 보인다는 이유만으로 `기준일 경과`로 판정하지 않는다.

## 출처 기록

각 핵심 사실에 다음을 붙인다.

- 출처 종류와 파일명 또는 공식 URL
- PDF·계약서는 페이지, 표제부·전유부·갑구·을구 등 근거 위치
- 원문 기준일
- 조회·확인일
- 원문 값
- 최신 조회값
- 상태
- 대표님 판단 또는 후속 확인

## 충돌 처리

- 값 하나를 임의로 선택하지 않는다.
- `자료 없음`을 `해당 없음`이나 `문제 없음`으로 바꾸지 않는다.
- MCP 실패를 원문 부재로 해석하지 않는다.
- 법령은 법령명, 조문, 시행일과 조회일을 기록한다.

## 실행 상태

증거 상태 6종과 별도로 외부 조회 절차를 다음처럼 기록한다.

| 실행 상태 | 적용 기준 |
|---|---|
| 승인 대기 | 입력·마스킹 승인이 없어 조회를 시작하지 않음 |
| 조회 미수행 | 승인 후에도 해당 조회를 아직 실행하지 않음 |
| 조회 완료 | 공식 응답을 받고 출처·확인일을 기록함 |
| 조회 실패 | 빈 결과, 연결 오류, 일시적 장애 등으로 공식 응답을 확보하지 못함 |
