# 매물 유형별 추가 검수

공통 필드는 주소, 거래 유형, 가격, 면적, 용도, 권리관계 메모, 현장 메모, 매수 목적이다. 대분류와 세부유형을 선택하고 목록에 없으면 직접 입력한다.

## 주거

- 아파트, 오피스텔, 연립·다세대, 단독·다가구
- 동·호, 전유·공용면적, 대지권, 사용승인일, 주차, 관리비
- 임대차 보증금, 차임, 기간, 갱신 여부

## 상업업무

- 상가, 점포, 사무실, 상가건물, 빌딩, 지식산업센터
- 층별 공부상 용도와 실제 사용, 임차 업종, 공실
- 보증금·월세·부가세·관리비·계약기간
- 대지·건축·연면적, 건폐율·용적률, 주차
- 상권과 접근성의 공식 근거

## 산업물류

- 공장, 창고, 제조시설, 물류시설
- 용도지역, 공장등록·업종 제한 확인 필요 여부
- 진입도로, 차량 접근, 층고, 전력, 하역시설
- 공부상 용도와 실제 사용의 일치 여부

## 토지

- 대지, 전·답, 임야, 개발부지
- 지목, 면적, 용도지역·지구·구역, 도로 접면
- 개발행위·농지·산지 관련 추가 검토 필요 여부
- 현재 이용상태와 공부상 지목 차이

## 특수기타

- 숙박, 의료, 종교, 주유소, 주차장, 기타 복합용도
- 법정 주용도와 세부용도
- 인허가·등록·시설 기준의 별도 확인 필요 여부
- 영업권·시설·부동산 가치의 분리

## 매수 목적

- 투자: 임대현황, 공실, 기초 수익표, 계약 안정성
- 직접사용: 인도 가능일, 현재 사용, 용도·시설 적합성
- 법인사옥: 공간 구성, 접근성, 주차, 입주 가능성
- 개발검토: 공법상 제한과 인허가를 단정하지 않고 추가 검토 항목으로 제시
