# 실제 파일럿 체크리스트

## Before

- 같은 케이스를 수작업으로 먼저 처리한다.
- 고객 회신과 자료 발급 대기시간은 활동시간에서 제외한다.
- 단계별 시작·종료와 메모를 기록한다.
- 동일 사례 재사용에 따른 학습효과가 있음을 기록한다.

## 입력

- 원본과 `automation-masked` 폴더가 분리됨
- 동의일과 동의 범위가 기록됨
- 임차인의 주민등록번호, 계좌번호, 서명, 개인 연락처가 마스킹됨
- 계약서 1~5건의 페이지 수와 중복 여부를 확인함

## 품질 통과

- 핵심 수치 오류 0건
- 발견 가능한 자료 충돌 전부 표시
- 미확인 상태를 지정 상태값으로 분리
- 단정적 권리·적법성·수익 보장 표현 0건
- 고객용 문구와 내부 검수 메모 분리
- 수익 계산식과 제외항목 표시

## After

- 입력 준비, Codex 처리, MCP 조회, 사람 검수, 수정, 기록 시간을 분리함
- 수정 요청 횟수와 변경 내용을 기록함
- 공개본에서 주소, 의뢰인·임차인 정보, Drive·Sheet·Apps Script 주소를 제거함
- Plan, 입력, 대조표, 승인, Before/After, 최종 미리보기 캡처 위치를 남김
