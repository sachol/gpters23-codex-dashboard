# Week 2 실제 상가·빌딩 파일럿 체크리스트

## 0. 파일럿 대상

- [ ] 실제 상가·빌딩 1건
- [ ] 임대차계약서 1~5건
- [ ] 건축물대장 또는 조회 결과
- [ ] 등기사항전부증명서
- [ ] 토지이용계획확인서 또는 토지이음 공식 조회 결과
- [ ] 실거래 또는 주변 시세 공식 근거
- [ ] 의뢰인 설명값: 주소, 매도가, 보증금, 월세, 임대차기간

## 1. 비식별·동의

- [ ] 자료 처리 목적과 범위 동의일 기록
- [ ] 원본 Drive 폴더와 `automation-masked` 폴더 분리
- [ ] 성명, 전화번호, 주민등록번호, 계좌, 서명·도장 등 비식별
- [ ] Codex에는 마스킹 폴더 ID만 전달
- [ ] 페이지 누락·중복·판독 불가를 목록으로 기록
- [ ] 1단계 `입력자료·비식별 처리` 사람 승인

## 2. Before 실측

- [ ] 동일 자료를 기존 수작업으로 먼저 처리
- [ ] 의뢰 접수
- [ ] 자료 정리·마스킹
- [ ] 공적 자료 교차검증
- [ ] 임대차 대조
- [ ] 입지·상권 조사
- [ ] 제안서 작성
- [ ] 사람 검수·수정
- [ ] 고객 회신 대기시간 제외
- [ ] 각 단계 활동시간과 수정 횟수 기록

## 3. Codex 실행

- [ ] 비공개 앱에서 매물 유형 `상업업무 / 상가·빌딩` 선택
- [ ] 매수 목적 선택
- [ ] 실행 프롬프트 복사
- [ ] `$property-briefing` Skill로 마스킹 자료 검토
- [ ] 건축물대장 MCP 조회
- [ ] 상업업무용 실거래 MCP 조회
- [ ] 쟁점이 있을 때만 국가법령정보센터 MCP 조회
- [ ] 최신 입지·상권·교통·개발계획은 공식 기관 자료로 확인

## 4. 교차검증

- [ ] 주소·용도·면적·소유관계 등 핵심 수치 대조
- [ ] 원문 값과 최신 조회값을 병렬 표시
- [ ] 발견 가능한 충돌 전부 표시
- [ ] `자료 없음 / 추가 확인 필요 / 기준일 경과 / 불일치 / 판독 불가` 구분
- [ ] 계약별 보증금·월세·기간 대조
- [ ] 계약서 합계 재계산
- [ ] 기초 임대수익률의 입력값·계산식·제외항목 표시
- [ ] 2단계 `공적 자료·임대차 교차검증` 사람 승인

## 5. 결과 분리

- [ ] 고객용 제안서에 검증된 값과 조건부 표현만 사용
- [ ] 내부 검수표에 충돌·추가 질문·자료 한계 기록
- [ ] 고객용 결과에 개인정보·비공개 링크·내부 메모 없음
- [ ] 권리 안전성·적법성·수익 보장 표현 없음
- [ ] 인쇄/PDF 미리보기에서 내부 영역 제외 확인
- [ ] 3단계 `고객용·내부용 분리` 사람 승인

## 6. After 실측과 사례 증거

- [ ] 동일 자료로 Codex 방식 활동시간 측정
- [ ] 단계별 수정 횟수 기록
- [ ] 동일 사례 재사용에 따른 학습효과 한계 기록
- [ ] 정확성, 충돌 탐지, 사람 검수 시간도 함께 비교
- [ ] Plan, Goal, 입력, MCP, 충돌표, 승인, Before/After, 최종 미리보기 화면 캡처
- [ ] 승인된 비식별 요약만 공개 보드에 반영
- [ ] 사례글 `소개 / 진행 방법 / 결과와 배운 점 / 도움 받은 글` 갱신
